# 🥗 Kalkulator Kalorii i Makroskładników

Aplikacja webowa napisana w języku Python przy użyciu frameworka **Streamlit**, służąca do szybkiego i intuicyjnego przeliczania wartości odżywczych oraz kalorii dla dowolnych porcji jedzenia.

---

## 🚀 Demo na żywo

Aplikacja jest wdrożona i dostępna publicznie pod adresem:
👉 **https://calculator-kcal.streamlit.app/**

---

## ✨ Funkcje

* 📊 **Precyzyjne przeliczanie:** Automatyczne obliczanie kaloryczności oraz makroskładników (białko, węglowodany, tłuszcze) na podstawie wybranej wagi porcji.
* ⚡ **Natychmiastowe wyniki:** Interaktywny interfejs przelicza wartości na żywo podczas zmiany parametrów.
* 📱 **RWD (Responsive Design):** W pełni dostosowany wygląd zarówno do ekranów komputerów, jak i urządzeń mobilnych.

---

## 🛠️ Technologie

* **Python 3.x**
* **Streamlit** (Frontend & UI)
